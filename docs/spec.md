# Initial experiment

Implement an explicitly limited two-player Mindbug experiment using the separately versioned turn-kernel package. JSON custom card definitions; TS behavior. Fixed decks, 3 life, 2 Mindbugs, up to 5 cards in hand with immediate refill. Play, opponent takeover decision (extra turn for original player on takeover), attack, block, optional Hunter target, Tough defeat replacement, optional second Frenzy attack if surviving, zero-life/no-legal-action loss. No original artwork or card text, expansion mechanics or arbitrary triggered abilities. Explicit serializable action/mindbug/block/frenzy/finished states. Validate player, zone, controller, typed reference, session and revision. Resume all waiting states; repeated inputs and invalid snapshots reject. Full state view is a trusted debug interface, not a multiplayer player view. Tests and terminal demo, no editor or browser UI.
